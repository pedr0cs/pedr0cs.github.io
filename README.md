# 🌐 Pedro Guerra — Portfolio 

Repositório do meu site pessoal/portfólio, desenvolvido para apresentar meus projetos de desenvolvimento backend, estudos de ciência da computação e formas de contato.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura semântica e acessível da aplicação.
- **CSS3:** Estilização moderna, responsividade e efeito animado de chuva de código binário (*Matrix effect*).
- **JavaScript (ES6+):** Scripts de interatividade e comportamento dinâmico.
